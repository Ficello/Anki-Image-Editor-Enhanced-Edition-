Image Editor Enhanced — Fast Crop, Annotate & Medical Image Tools

An advanced, high-performance image editing, cropping, and annotation add-on for Anki. Crop, rotate, straighten, redact, annotate, and invert medical illustrations directly within the Note Editor in seconds without interrupting your review or card creation workflow.

Key Enhancements vs Original Add-on (789309990)

  • Built-in Fast Cropper: Instant cropping dialog with aspect ratio presets (Free, 1:1, 4:3, 16:9, 3:2), lossless rotations (-90° / +90°), horizontal and vertical flips, live dimensions badge, and zoom controls.
  • In-Place Medical Redaction & Blackout: Instant blackout tool directly on the cropper to mask patient names, confidential data, or identifiers without opening external tools.
  • Quick In-Place Annotations: Draw pointer arrows, focus frames, and semi-transparent highlighters directly onto the cropper canvas.
  • Fine Tilt / Straighten Slider: Precision rotation slider (-45° to +45°) to straighten crooked book photos, scans, and ECG tracings.
  • Medical Image Filters: One-click Invert (Negative) filter for X-rays and CT scans, plus High Contrast and Grayscale modes.
  • Lossless Full Editor Transition: Cropped regions and in-place annotations are preserved and carried directly into Method-Draw when switching to vector editing.
  • Floating Bubble Menu Integration: Injects an Image Editor action button directly into Anki's floating image popover.
  • Native Settings Dialog & config.md: Dedicated Qt configuration interface and comprehensive Markdown help pane.
  • Full Internationalization (i18n): Native translation into over 40 Anki languages with automatic locale detection.
  • Robust UTF-8 Handling: Full compatibility with accented and international filenames.
  • Minimalist & Sober Design: Clean, clinical-grade interface following strict design principles (zero emojis).

How to Use

  1. Floating Toolbar: Select an image and click the Image Editor icon in the floating bubble toolbar.
  2. Context Menu: Right-click any image and choose Image Editor (Crop / Edit).
  3. Toolbar Button / Shortcut: Press Ctrl + Shift + I to edit the selected image, or open a blank canvas to create a new vector drawing from scratch.
  4. Fast Crop & Annotation Tools:
    • Select a ratio preset or adjust the crop boundaries.
    • Use the Redact tool (B) to black out confidential information.
    • Use the Arrow (A), Frame, or Highlight tools for quick visual cues.
    • Adjust the Tilt slider to straighten misaligned images.
    • Toggle Invert (I) to examine radiographic negative images.
  5. Switch to Full Vector Editor: Click Full Editor to carry over your crop and annotations into Method-Draw for complex shapes and text labels.

Keyboard Shortcuts

  • Ctrl + Shift + I: Open Image Editor on selected image (or open blank drawing).
  • Enter: Save and apply changes.
  • Esc: Cancel and close dialog.
  • Ctrl + Z: Undo last drawn annotation.
  • C: Crop tool.
  • B: Redaction / Blackout tool.
  • A: Pointer arrow tool.
  • I: Invert colors (Negative / X-ray).
  • R / L: Rotate right / left (+90° / -90°).
  • H / V: Flip horizontal / vertical.
  • 1 to 5: Ratio presets (Free, 1:1, 4:3, 16:9, 3:2).
