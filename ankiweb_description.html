Image Editor (Enhanced Edition) - Fast Crop, Annotate & Draw

An advanced, high-performance image editing and cropping add-on for Anki. Crop, rotate, flip, annotate, and edit images directly within the Note Editor in seconds without interrupting your review or card creation workflow.

Key Enhancements vs Original Add-on (789309990)

  • Built-in Fast Cropper: Instant cropping dialog with aspect ratio presets (Free, 1:1, 4:3, 16:9, 3:2), lossless rotations (-90° / +90°), horizontal and vertical flips, live dimensions badge, and zoom controls.
  • Floating Bubble Menu Integration: Injects an Image Editor action button directly into Anki's floating image popover.
  • Full Internationalization (i18n): Native translation into over 40 Anki languages (French, German, Spanish, Japanese, Chinese, Russian, Italian, Portuguese, Arabic, Korean, and many more) with automatic locale detection.
  • Robust UTF-8 Handling: Full compatibility with international and non-ASCII filenames.
  • Minimalist & Sober Design: Clean, modern interface without distractions or emojis.

How to Use

  1. Floating Toolbar: Select an image and click the Image Editor icon in the floating bubble toolbar.
  2. Context Menu: Right-click any image and choose Image Editor (Crop / Edit).
  3. Toolbar Button / Shortcut: Press Ctrl + Shift + I to edit the selected image, or open a blank canvas to create a new vector drawing from scratch.
  4. Switch to Full Vector Editor: From the Cropper, click Full Editor (Shapes / Text) to add arrows, text labels, shapes, and freehand drawings.

Keyboard Shortcuts

  • Ctrl + Shift + I: Open Image Editor on selected image (or open blank drawing).
  • Enter: Save and apply crop.
  • Esc: Cancel and close dialog.
